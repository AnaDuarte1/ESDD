# 🧠 Disciplina de Estrutura de Dados

Repositório criado para armazenar atividades, exercícios, implementações e projetos da disciplina **Estrutura de Dados**, ministrada no curso de Sistemas para Internet do **IFSP – Campus Araraquara**.

---

## 📚 Conteúdos Abordados

- Introdução às Estruturas de Dados
- Complexidade de algoritmos (notação O)
- Vetores e Matrizes
- Listas Lineares:
  - Listas Estáticas (Vetores)
  - Listas Encadeadas Simples
  - Listas Duplamente Encadeadas
- Pilhas (Stacks)
- Filas (Queues)
- Recursão
- Árvores:
  - Árvores Binárias
  - Árvores Binárias de Busca (BST)
- Tabelas Hash
- Grafos (introdução)
- Aplicações práticas em C/C++

---

## 🛠 Tecnologias Utilizadas

- **Linguagem C**
- **Dev C++ / Code::Blocks / VS Code**
- **Git e GitHub**
- Compilador GCC
